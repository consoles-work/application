# DevConsole Hub — Правила работы

Обязательны для любой задачи в этом проекте. Перед началом работы — перечитать.

---

## 1. План и статус всегда актуальны

`docs/PLAN.md` и `docs/STATUS.md` должны отражать реальное состояние проекта.

- **Перед началом** новой фичи или заметной правки — записать в `docs/PLAN.md`, что планируем сделать: новый этап или подпункт существующего этапа со статусом `TODO` / `В РАБОТЕ`.
- **После завершения** — в той же задаче, не откладывая:
  - `docs/PLAN.md`: пункт перевести в `ВЫПОЛНЕНО` (с датой) и описать, что фактически сделано — файлы, команды, поля БД, ограничения;
  - `docs/STATUS.md`: запись в «Историю изменений» (дата, кратко, ссылка на этап в PLAN.md), поправить таблицы файлов, «Что осталось сделать» и строку «Последнее обновление».
- В обоих файлах обновлять строку `> Последнее обновление: ...` с датой.
- Если план поменялся по ходу работы (что-то отложили, сделали иначе) — отразить это, а не оставлять старый текст.
- Задача не считается завершённой, пока эти два файла не обновлены.

## 2. Версии

Версия приложения живёт в одном месте — `package.json`. `tauri.conf.json` ссылается на него (`"version": "../package.json"`), фронт получает её при сборке (`__APP_VERSION__`, `src/lib/appInfo.ts`). Копии в `package-lock.json`, `src-tauri/Cargo.toml` и `Cargo.lock` руками не правятся — их переписывает скрипт.

- `npm run version:check` — показать версию и проверить, что копии совпадают.
- `npm run version:bump -- patch | minor | major | X.Y.Z` — поднять версию. Раздел «Не выпущено» в `CHANGELOG.md` становится разделом новой версии с датой. В git скрипт ничего не пишет (поэтому не `npm version` — тот сам коммитит и ставит тег).

Схема SemVer, пока версия `0.x`:
- **patch** (`0.2.0 → 0.2.1`) — исправления без новых возможностей;
- **minor** (`0.2.1 → 0.3.0`) — новые возможности, а также несовместимые изменения формата БД или `.dchub`;
- **major** (`1.0.0`) — когда приложение будет считаться стабильным релизом.

Порядок:
- Каждая заметная правка, вместе с записью в PLAN/STATUS, добавляет строку в `CHANGELOG.md` → «Не выпущено» (разделы «Добавлено» / «Изменено» / «Исправлено»).
- Версия поднимается перед сборкой, которая уходит пользователям (`npm run tauri build`), а не на каждую правку. Поднятие — решение владельца.
