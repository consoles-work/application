## [Не выпущено]

### Добавлено
- Секция «Недавние» внизу левой панели, под деревом: 5 последних использованных консолей для быстрого перехода. Видно, у каких открыта сессия и какие помечены как опасные; правый клик — обычное меню консоли; консоль можно убрать из списка крестиком, весь список — очистить (с подтверждением); секцию можно свернуть
- Раздел «SSH-ключи» (кнопка с ключом в заголовке окна): какие ключи есть в `~/.ssh`, их тип, стойкость, passphrase, права, загружены ли в ssh-agent, какие консоли и хосты из `~/.ssh/config` их используют. Аудит проблем с объяснением и советом: ключ без passphrase, слабый алгоритм, открытые права, отсутствующий файл, один ключ на несколько воркспейсов, прод-консоль на незащищённом ключе, проброс агента, отключённая проверка ключа хоста. Действия: скопировать публичный ключ или отпечаток, исправить права, создать ключ ED25519. Всё локально — к серверам приложение не подключается
- Подсказка под полем ключа в форме консоли: файл не найден, ключ без passphrase, неверные права

### Изменено
- Dev-сборка на macOS подписывается постоянным сертификатом (`scripts/dev-sign-run.sh`)

### Исправлено
- После прерванной по `^C` программы (например, `docker logs -f` с цветными логами) её цвет оставался включённым — приглашение и весь дальнейший вывод становились серыми. Теперь цвет сбрасывается при Enter и Ctrl+C
- Предупреждение `dead_code` (`about_label`) при сборке под Linux и Windows: функция нужна только меню приложения macOS

## [0.1.0] — 2026-10-17

Стартовая точка: всё, что сделано до введения версий (этапы 1–25 в `docs/PLAN.md`).

- Четыре панели: дерево воркспейсов / проектов / консолей, терминал (xterm.js + PTY), wiki (TipTap, FTS5-поиск), AI-ассистент (OpenAI, Anthropic, Ollama, Claude Code CLI)

- Шифрованная БД (SQLCipher), пароль на вход и автоблокировка
- Экспорт / импорт `.dchub` (AES-256-GCM), публичный экспорт списка серверов в Markdown
- Статистика использования, 18 тем, 5 языков, системный трей, автозапуск, один экземпляр приложения
