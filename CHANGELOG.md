## [0.1.0] — 2026-10-17

Стартовая точка: всё, что сделано до введения версий (этапы 1–25 в `docs/PLAN.md`).

- Четыре панели: дерево воркспейсов / проектов / консолей, терминал (xterm.js + PTY), wiki (TipTap, FTS5-поиск), AI-ассистент (OpenAI, Anthropic, Ollama, Claude Code CLI)
- SSH: ключ, passphrase, пароль; быстрые команды консоли со счётчиком сэкономленного времени
- Шифрованная БД (SQLCipher), пароль на вход и автоблокировка
- Экспорт / импорт `.dchub` (AES-256-GCM), публичный экспорт списка серверов в Markdown
- Статистика использования, 18 тем, 5 языков, системный трей, автозапуск, один экземпляр приложения
