# Публикация в Telegram-канал проекта

Пост уходит в сервис koval-autopost, а тот публикует его в канал ботом
проекта. Куда и с каким ключом — в `config.env` рядом с этим файлом
(адрес сервиса, проект, ключ). Ключ — секрет: не печатать его, не
вставлять в посты, не коммитить (`config.env` уже в `.gitignore` скилла).

Скрипт — `scripts/post.py` в каталоге этого скилла, только стандартная
библиотека Python 3. Ниже `$S` — путь к каталогу скилла
(обычно `.claude/skills/autopost`).

## Перед первой публикацией в сессии

```bash
python3 $S/scripts/post.py check
```

«всё готово» — можно публиковать. Иначе передать пользователю причину
дословно (бот не администратор, нет права публикации, ключ-заглушка в
`config.env`) — сам скилл это не чинит.

## Как публиковать

1. **Текст** — в файл (например, во временный каталог), в обычном
   Markdown: `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `||скрытый||`,
   `` `код` ``, блоки ```` ``` ````, `[текст](https://…)`, `> цитата`,
   `# заголовок` (станет жирной строкой), списки `- пункт` (станут «•»).
   Сервис сам переведёт это в разметку Telegram — экранировать ничего не
   нужно. Таблиц и картинок внутри текста Telegram не умеет.
2. **Лимиты Telegram** (видимые символы, после разметки): текст — до 4096;
   подпись к картинке — до 1024. Длиннее 1024 при картинках — не ошибка:
   картинки выйдут отдельно, текст следом вторым сообщением. Картинки — до
   10 (2–10 — альбом), файлы JPEG/PNG/WEBP до 10 МБ или ссылки `https://`.
3. **Согласовать**: публикация видна всем подписчикам сразу. Если
   пользователь не сказал явно «публикуй без показа» — сначала показать
   ему итоговый текст и список картинок и дождаться «да».
4. **Опубликовать**:

   ```bash
   python3 $S/scripts/post.py send --text-file /tmp/post.md --image cover.png
   ```

   Ещё: `--image` несколько раз (альбом), `--at 2h` или
   `--at 2026-11-20T09:00+03:00` (отложить; время — с поясом), `--silent`
   (без звука у подписчиков), `--no-preview` (без превью ссылок),
   `--format html` (если текст уже в Telegram HTML), `--dry-run` (показать
   запрос, ничего не отправляя).
5. **Итог — пользователю**: ссылку на пост (`опубликован: https://t.me/…`)
   и id поста. Код выхода 2 — пост в очереди (Telegram временно
   недоступен), сервис повторит сам; проверить позже `post.py status ID`.
   Код 1 — ошибка: передать текст ошибки, не повторять вслепую.

Повторный запуск `send` после обрыва связи безопасен только внутри одного
запуска (скрипт сам повторяет запрос с тем же ключом идемпотентности).
Запустить `send` второй раз с тем же текстом — это **второй пост**: если
непонятно, вышел ли первый, сначала `post.py list`.

## Другие команды

```bash
python3 $S/scripts/post.py status ID   # состояние и ссылка
python3 $S/scripts/post.py delete ID   # отменить отложенный или удалить из канала
python3 $S/scripts/post.py list        # последние посты проекта
```

Удалить из канала Telegram даёт только посты моложе 48 часов. Удаление —
по прямой просьбе пользователя, не «для исправления опечатки» без
спроса.
